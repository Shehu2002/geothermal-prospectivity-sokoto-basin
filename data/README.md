# Data Sources

This directory documents the datasets used in the geothermal prospectivity assessment.

The research uses geospatial and geophysical information, including:

- Landsat 8/9 thermal data.
- NASADEM/SRTM elevation data.
- Normalized Difference Vegetation Index (NDVI).
- Geological structural information.
- Regional heat-flow observations.
- Radiogenic heat production data.

The original datasets are not included in this repository. Their sources, processing details and access information will be documented here.
